## Given rules and the Turn 3 intervention

The case-local rule assigns evidence scope: the genealogy supports inheritance
relationships; the trade chart supports flows, values and period comparisons.
Neither page alone establishes a causal link between succession and trade.
Turn 3 asks for a hypothetical missing-page deduction: remove the genealogy,
retain the silver-flow chart, and state which judgments lose support and which
remain available. The hypothetical removal must not overwrite the real
archive, which still contains both pages.

## Reference answer for Turn 3

> Under the missing-page deduction only, remove or downgrade claims whose
> visible evidence is image_1.png: `The English Succession to 1603`, the
> `TUDORS`/`STUARTS` branches, and the inheritance relationship connecting
> `Elizabeth I (1558–1603)` and `James VI and I (1603–1625)`. Do not present
> those genealogy details as currently visible in the hypothetical package.
>
> Retain image_2.png and its comparison of `1600–1650 C.E.` with
> `1725–1750 C.E.`. `Western Europe` changes from Import `158 Tons` and
> Re-export `110 Tons` to Import `230 Tons` and Re-export `270 Tons`.
> `Americas` changes from Export `302 Tons` and Use `66 Tons` to Export
> `533 Tons` and Use `117 Tons`. `East and South Asia` Import changes from
> `109 Tons` to `193 Tons`; `Japan` Export changes from `59 Tons` to `0 Tons`.
> The `Southern African Route` changes from `16 Tons` to `160 Tons`, and
> `The Pacific Route` changes from `34 Tons` to `33 Tons`.
>
> Removing the genealogy does not invalidate those trade observations. It
> removes the in-diagram support for the succession narrative. Neither the
> retained trade values nor the hypothetical exercise establishes that the
> succession in 1603 caused changes in silver flows. This removal is an
> analytical hypothetical only: the real two-page archive is unchanged.
